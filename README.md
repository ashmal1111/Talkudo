# Talkudo - Modern Chat Application

## Features
- Real-time messaging
- Multi-client support
- File sharing & voice messages
- AI Assistant
- Dark/Light theme

## Quick Install
```
git clone https://github.com/ashmal1111/Talkudo.git
cd Talkudo
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
python run_server.py
```
